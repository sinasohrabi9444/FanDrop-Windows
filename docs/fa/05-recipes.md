# ۵. سناریوهای کاربردی و ترفندها

کارهای روزمره‌ای که با FanDrop چند ثانیه طول می‌کشن.

---

### 📱 عکس‌های آیفون (HEIC) رو JPG کن

همه‌ی HEICها رو انتخاب کن ← بکش ← <kbd>Shift</kbd> ← **JPG**.
یه نوتیفیکیشن «Saved 24 files» میاد. با کلیک روش پوشه باز می‌شه.

### 💬 عکس رو برای تلگرام / واتس‌اپ سبک کن

بکش ← <kbd>Ctrl</kbd> ← **Compress** (JPG با کیفیت ۶۰٪).
اگه ابعاد خیلی بزرگه، اول **Resize 1280**، بعد Compress روی خروجی.

### 🕵️ قبل از انتشار عکس، مکان GPS رو پاک کن

بکش ← <kbd>Ctrl</kbd> ← **Strip metadata**.
برای JPG کیفیت هیچ تغییری نمی‌کنه؛ فقط EXIF (مکان، مدل گوشی، تاریخ) حذف می‌شه. برای ویدیو و صدا هم همین تیغه هست.

### 🎞️ از یه ویدیو GIF بساز

اول ویدیو رو کوتاه کن: <kbd>Ctrl</kbd> ← **First 10s**.
بعد خروجی رو از `Downloads\FanDrop` بکش ← <kbd>Shift</kbd> ← **GIF**.

### 📉 ویدیوی گوشی رو برای ایمیل کوچیک کن

بکش ← <kbd>Ctrl</kbd> ← **Compress**. خروجی MP4 با H.264 که همه‌جا پخش می‌شه.
برای ویدیوهای طولانی چند ثانیه تا چند دقیقه طول می‌کشه؛ وقتی کار در جریانه، روی آیکون tray نوشته *FanDrop — working…*.

### 🎵 صدای یه ویدیو رو دربیار

بکش ← <kbd>Shift</kbd> ← **MP3**.

### 🎙️ ویس یا پادکست رو آماده‌ی انتشار کن

1. <kbd>Ctrl</kbd> ← **Normalize** (یکسان‌سازی بلندی صدا)
2. خروجی رو بکش ← <kbd>Ctrl</kbd> ← **Mono**
3. خروجی رو بکش ← <kbd>Ctrl</kbd> ← **Compress** (MP3 96k)

### 🖼️ صفحه‌های PDF رو عکس کن

بکش ← <kbd>Shift</kbd> ← **PNG**. هر صفحه یه فایل: `report - page 1.png`، `report - page 2.png`، …

### 📄 چند عکس رو PDF کن

هر عکس با <kbd>Shift</kbd> ← **PDF** یه PDF تک‌صفحه‌ای می‌شه.

### ✂️ متن یه فایل Word رو سریع کپی کن

بکش ← <kbd>Ctrl</kbd> ← **Copy text**. حالا هر جا خواستی Paste کن — بدون باز کردن Word.

### 🔢 تعداد کلمه‌های مقاله

بکش ← <kbd>Ctrl</kbd> ← **Word count**. عدد توی نوتیفیکیشن میاد و کپی هم می‌شه.

### 📦 یه پوشه‌ی پروژه رو زیپ کن

پوشه رو بکش ← <kbd>Shift</kbd> یا <kbd>Ctrl</kbd> ← **ZIP**.
چند فایل و پوشه با هم ← یه `Archive.zip`.

### 🔐 بررسی سلامت فایل دانلودی

بکش ← <kbd>Shift</kbd> ← **SHA-256**. هش کپی می‌شه؛ با هشی که سایت داده مقایسه کن.

### 🔗 مسیر کامل یه فایل رو برای ترمینال کپی کن

بکش ← <kbd>Alt</kbd> ← **Copy path**.

### 👀 یه نگاه سریع بدون باز کردن برنامه

بکش ← <kbd>Alt</kbd> ← **Quick Look**. با <kbd>Space</kbd> می‌بندی.

---

## ⚡ ترفندها

- **عوض کردن حالت وسط کار:** با <kbd>Shift</kbd> باز کردی؟ <kbd>Ctrl</kbd> بزن، تیغه‌ها عوض می‌شن.
- **عوض کردن پوشه‌ی خروجی:** متغیر محیطی `FANDROP_OUT` رو ست کن، مثلاً `D:\Converted` ([آموزش ۷](07-build-and-develop.md#env)).
- **زنجیره‌ی کارها:** خروجی‌ها توی `Downloads\FanDrop` هستن؛ اون پوشه رو باز نگه دار و خروجی هر مرحله رو دوباره بکش.
- **فایل از مرورگر:** عکس رو مستقیم از صفحه‌ی وب بکش و رها کن، لازم نیست اول ذخیره‌اش کنی.
- **همیشه آماده:** راست‌کلیک روی آیکون ← **Start with Windows**.
